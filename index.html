# Midnight Cat — GitHub Pages starter A tiny, cozy, click-to-pet browser experience. ## Publish with GitHub Pages 1. Create a new public repository on GitHub (for example `midnight-cat`). 2. Upload `index.html` to the repository's root. 3. Open **Settings → Pages**. 4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then Save. 5. Wait for GitHub to publish the site. The Pages URL will appear in Settings → Pages. ## Notes - This is a self-contained HTML/CSS/JS prototype. It does not need a build step. - The cat is currently drawn with CSS shapes, so this is a functional visual prototype rather than a photorealistic 3D cat. To reach the realism described, replace the CSS cat with a properly licensed high-quality 3D cat model and animation (GLB), then render it with Three.js/WebGL. - The sound toggle synthesizes a very quiet low tone; it is not a recorded cat purr.
